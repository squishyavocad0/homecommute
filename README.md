# homecommute
Our House is a mobile-first web app (PWA) for a shared house with four housemates.

🚦 Traffic lights: see at a glance if the washing machine, dryer, toilet or shower is free (green), in use (red) or done / airing out (orange). Washer and dryer show whose laundry it is; toilet and shower stay anonymous. Timers switch lights automatically.

🧽 Chore schedule: a rolling 7-week schedule that generates itself and keeps everyone's number of cleans equal. Weekly chores can be ticked Thu–Sun, 2-week chores only in their second week. Finished weeks move to a history log, and missed or late chores land in the Hall of Shame.

Built with Next.js, Supabase (realtime + pg_cron) and Vercel.
